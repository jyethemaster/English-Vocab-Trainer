# English Word Trainer (英単語トレーナー) — GitHub Pages PWA

Upload all files in this folder to the **root** of your GitHub repository:
`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`.

Then: **Settings → Pages → Deploy from a branch → `main` / `(root)`**.

## Notes
- A2-level English words with Japanese meanings (about 200 words in 8 topic units: People, Home & Food, Travel, Work & School, Health, Shopping, Free Time, Weather & Feelings). Games: Hangman, Memory, Prepositions, A or An, Sentences, Phrases, Synonyms, Crossword, Word Rain, My Words, Irregular Verbs, Progress.
- Add your own words in **My Words** (format: `word = 日本語`).
- Saved progress uses its own storage keys (`et`, `et_*`), so it will not clash with the Dutch trainer on the same GitHub Pages domain.
